# Day-005: Create a Makefile for ML Workflow Automation

## Overview

This lab focused on fixing and standardizing a Makefile used for automating machine learning workflows in the `fraud-detection` project.

The task involved:

- Reviewing a broken Makefile
- Fixing incorrect recipe indentation
- Adding missing targets
- Defining `.PHONY` targets
- Automating setup, data processing, training, testing, and cleanup workflows
