# Day-010: Install and Initialize DVC in an ML Project

## Overview

This lab focused on setting up DVC (Data Version Control) inside the existing `fraud-detection` Git repository.

The task involved:

- Initializing DVC inside the repository
- Creating DVC tracking configuration
- Staging generated DVC files
- Recording the initialization in Git
- Preparing the project for dataset and model versioning
