# Lab 01 — Build Complete DVC ML Pipeline with Remote Storage and Experiments

## Objective

Complete the fraud-detection production DVC pipeline by fixing the existing configuration, adding missing stages, running the workflow, pushing artifacts to remote storage, and creating a release tag.

---

## Task Summary

The project already contained:

- Git repository
- DVC repository
- SeaweedFS remote
- Existing stages:
  - ingest
  - validate
  - preprocess

Two stages were missing:

- train
- evaluate

Additionally, one existing stage contained an incorrect output path that prevented pipeline execution.

## Step 1 — Inspect Existing Pipeline

Review the current pipeline:

```bash
cat dvc.yaml
```

Inspect the preprocessing script:

```bash
cat scripts/preprocess.py
```

The script writes:

```python
df.to_csv("data/processed/clean.csv", index=False)
```

---

## Problem Identified

### Existing DVC Output

```yaml
preprocess:
  outs:
    - data/processed/cleaned.csv
```

### Actual Script Output

```text
data/processed/clean.csv
```

The output path did not match the file generated by the script.

---

## Fix the Preprocess Stage

Replace:

```yaml
outs:
  - data/processed/cleaned.csv
```

with:

```yaml
outs:
  - data/processed/clean.csv
```

## Step 4 — Add Train Stage

Requirements:

| Item | Value |
|--------|--------|
| Dependency | scripts/train.py |
| Dependency | data/processed/clean.csv |
| Parameters | n_estimators |
| Parameters | max_depth |
| Parameters | test_size |
| Parameters | random_seed |
| Output | models/model.pkl |
| Output | data/processed/test_split.csv |
| Metric | metrics.json |
| Metric Cache | false |

---

### Command

```bash
dvc stage add \
-n train \
-d scripts/train.py \
-d data/processed/clean.csv \
-p n_estimators,max_depth,test_size,random_seed \
-o models/model.pkl \
-o data/processed/test_split.csv \
-M metrics.json \
python scripts/train.py
```

## Errors & Fixes

### Error 1 — preprocess Stage Fails

#### Cause

DVC expected:

```text
cleaned.csv
```

but script generated:

```text
clean.csv
```

#### Fix

Update the output path in dvc.yaml.

---

### Error 2 — Train Stage Missing

#### Cause

Pipeline incomplete.

#### Fix

Create the train stage with:

```bash
dvc stage add
```

and parameter dependencies.

---

### Error 3 — Evaluation Report Not Generated

#### Cause

Evaluate stage not declared.

#### Fix

Add:

```yaml
evaluate:
```

to the pipeline.

---

### Error 4 — Metrics Not Visible

#### Cause

metrics.json not registered as a metric.

#### Fix

Use:

```bash
-M metrics.json
```

or:

```yaml
metrics:
```

with cache disabled.

---

## Key Learnings

- DVC stages must match actual script outputs
- Metrics and reports should be tracked differently
- Parameterized pipelines improve reproducibility
- DVC remotes separate artifacts from source code
- Release tags provide stable deployment references
- End-to-end pipelines simplify ML operations
