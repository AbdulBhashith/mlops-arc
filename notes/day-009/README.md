# Day-009: Create a Custom ML Project Template with Cookiecutter

## Overview

This lab focused on fixing and rendering a Cookiecutter template for standardized ML project generation.

The task involved:

- Correcting the `cookiecutter.json`
- Fixing Jinja2 template syntax
- Adding ML framework selection logic
- Updating template README generation
- Rendering a new ML project from the template
